# 표기가 다르지만 같은 개념으로 합칠 키프레이즈
#   형식:  변형표기 => 대표표기
#          변형1 | 변형2 => 대표표기      (여러 개를 한 줄에)
#  - 단수/복수, 대소문자, 하이픈(-)·소유격('s) 차이는 자동으로 합쳐지므로 적을 필요 없습니다.
#    (예: "Large Language Models" = "large language model", "meta analysis" = "meta-analysis")
#  - 논문 안에서 정의된 약어는 자동으로 풀어 씁니다. 예) "large language models (LLMs)" 이후의 LLM
#  - 대표표기에 적힌 모양은 참고용이며, 결과 표기는 실제 논문에서 가장 많이 쓰인 형태로 표시됩니다.
